# MekiLabs default community health files

Issue templates in this repository apply to every MekiLabs repository that has no `.github/ISSUE_TEMPLATE` folder of its own.

- `.github/ISSUE_TEMPLATE/security.yml`: the **Security** form, the single way to report a security problem. It applies the `security` label. The reporting standard is in `dev-wiki`: `work/standards/security/reporting-a-security-issue.md`.

Repositories with their own templates (`meki-backend`, `mekidoc`) keep a copy of `security.yml`. This repository is the source of truth: change the form here first, then update the copies.

This repository is public, as GitHub requires for organization-wide templates. Never add anything sensitive to it.
